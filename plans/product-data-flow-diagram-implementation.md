## Шаг 2. Разметка SVG-диаграммы
Структура (DOM-порядок = логика конвейера, слева направо):

1. **Источники** — контейнер `.flow-sources` с сеткой из 7
   `<img src="./assets/images/vector/<n>.svg?v=50" alt="…" loading="lazy"
   decoding="async">`: `01_yandex_direct`, `02_yandex_metrika`,
   `04_vk_ads`, `05_my_target`, `06_rtb_droid`, `09_plan_fakt`,
   `08_metrika_ecom`.
2. **Стрелка** → (переиспользуемый инлайн-SVG, `aria-hidden="true"`).
3. **Data Lake** — узел: `clickhouse.svg` + подпись «Data Lake (ClickHouse)».
4. **Стрелка** →
5. **Обработка** — узел: инлайн-SVG-иконка «воронка» (одноцветная,
   `currentColor`/`--text-muted`) + подпись «Обогащение и парсинг».
6. **Стрелка** →
7. **Data Mart** — узел: `mySql.svg` + подпись «Data Mart (MySQL)».
8. **Стрелка** →
9. **Визуализация** — узел: `powerBi.svg` + `excel.svg` (плитками) +
   подпись «Дашборды и выгрузки».

- Узлы — семантичные блоки; стрелки — отдельные элементы между узлами
  (каждая = свой инлайн-SVG-сегмент, чтобы позже навесить анимацию
  движения без переархитектуры).
- Стрелка: тонкая **пунктирная** линия (`stroke-dasharray`) + треугольное
  остриё (SVG `marker` или path), цвет `--text-muted`/`--guide-gray`.

## Шаг 3. CSS (в product-секцию `css/style.css`)
- Новые классы `.product-flow`, `.flow-node`, `.flow-sources`,
  `.flow-arrow`, `.flow-label` — через `:root`-переменные/классы сайта
  (FR-1a), без инлайн-стилей.
- **Десктоп:** `display:flex; align-items:center;` горизонтальный ряд;
  `max-width` ≈ ширина `.product-page`, центрирование; высота скромная
  (узел-лого ~32–40px, источники мельче, сетка 3–4 в ряд).
- **≤768px:** `flex-direction:column`; стрелки поворачиваются вниз
  (`transform: rotate(90deg)`), без дубля разметки; без горизонтального
  скролла.
- Нормализация лого: фикс. высота контейнера + `object-fit:contain`,
  чтобы разнокалиберные SVG стояли ровно; плитки Excel/Power BI — в
  одинаковых по размеру «карточках»-узлах.
- **Reduced-motion Variant B:** hover/переходы (если будут) НЕ
  оборачивать в `prefers-reduced-motion … none`.
- Подготовка к будущей анимации: дашевые линии оформить так, чтобы
  потом включить `stroke-dashoffset`-анимацию по сегментам (комментарий-
  хук в CSS, сама анимация сейчас НЕ добавляется — вне scope).
