# План рефакторинга лендинга Amigo

Данный план описывает пошаговое выполнение работ согласно утвержденной спецификации (`spec/refactoring_specification.md`).

## Шаг 1: Подготовка структуры директорий
- [x] Создать папку `css/`
- [x] Создать папку `js/`
- [x] Создать папки `assets/` и `assets/images/`

## Шаг 2: Извлечение изображений
- [x] Скопировать Data URI код SVG-изображения из CSS-класса `.cube` в `index.html`.
- [x] Создать файл `assets/images/cube-wireframe.svg` и поместить туда чистый SVG-код.

## Шаг 3: Выделение стилей (CSS)
- [x] Вырезать всё содержимое тега `<style>` из `index.html`.
- [x] Создать файл `css/style.css` и вставить туда извлечённые стили.
- [x] Обновить класс `.cube` в `style.css`: заменить длинный Data URI на относительный путь `url('../assets/images/cube-wireframe.svg')`.
- [x] В файле `index.html` заменить тег `<style>` на подключение внешнего файла: `<link rel="stylesheet" href="./css/style.css">`.

## Шаг 4: Оптимизация стилей (Пиксели -> Относительные единицы)
- [x] Провести аудит файла `css/style.css`.
- [x] Найти жестко заданные размеры в пикселях (`px`) для: `font-size`, `margin`, `padding`, `width`, `height`.
- [x] Пересчитать и заменить абсолютные величины (`px`) на относительные (`rem`, `em`, `%`, `vh`, `vw`), где это целесообразно (оставив `px` только для тонких границ/бордеров).

## Шаг 5: Выделение скриптов (JS)
- [x] Вырезать содержимое тега `<script>` в нижней части файла `index.html`.
- [x] Создать файл `js/main.js` и вставить туда извлечённый код.
- [x] Обернуть код внутри `main.js` в обработчик `document.addEventListener('DOMContentLoaded', ...)` для корректного запуска.
- [x] В файле `index.html` добавить подключение скрипта в конец body: `<script src="./js/main.js" defer></script>`.

## Шаг 6: Улучшение HTML, SEO и a11y
- [x] Добавить в `<head>` базовые SEO мета-теги (например, `description`).
- [x] Проверить HTML на наличие кнопок или интерактивных элементов без текста (если такие есть, добавить `aria-label`).
- [x] Убедиться в корректной семантике страницы.

## Шаг 7: Финальное тестирование
- [x] Открыть обновленный `index.html` в браузере (желательно через локальный сервер).
- [x] Убедиться, что верстка не сломалась и выглядит как в оригинале.
- [x] Проверить, что анимация кубиков при движении мыши в первом блоке работает корректно.
- [x] Проверить консоль разработчика на наличие ошибок 404 (все подключенные ресурсы загружаются успешно).
