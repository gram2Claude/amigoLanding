Политика обработки персональных данных

Настоящая Политика определяет порядок обработки и защиты персональных данных пользователей сайта Amigo (далее — «Сайт»), которые предоставляются через форму обратной связи «Оставить заявку».

1. Оператор персональных данных

Оператором персональных данных является [НАЗВАНИЕ ОПЕРАТОРА], ИНН [ИНН]. Контакт для обращений по вопросам обработки персональных данных: [E-MAIL ДЛЯ ОБРАЩЕНИЙ].

2. Состав обрабатываемых данных

При отправке заявки обрабатываются следующие данные, которые вы указываете добровольно:

  • имя;
  • адрес электронной почты;
  • номер телефона.

3. Цели обработки

Персональные данные обрабатываются исключительно для обратной связи с вами: рассмотрения заявки, подготовки ответа и предоставления запрошенной информации об услугах.

4. Правовые основания и согласие

Обработка осуществляется на основании вашего согласия, выражаемого путём проставления отметки в поле согласия при отправке формы. Согласие может быть отозвано направлением обращения на указанный выше адрес.

5. Передача данных

Для доставки заявки ответственному сотруднику данные передаются через сервис обмена сообщениями Telegram. Иным третьим лицам данные не передаются, за исключением случаев, предусмотренных законодательством Российской Федерации.

6. Срок хранения

Персональные данные хранятся в течение срока, необходимого для достижения целей обработки, а затем удаляются или обезличиваются, если иное не предусмотрено законодательством.

7. Права субъекта персональных данных

Вы вправе получать информацию об обработке ваших данных, требовать их уточнения, блокирования или удаления, а также отозвать согласие. Для реализации прав направьте обращение на адрес: [E-MAIL ДЛЯ ОБРАЩЕНИЙ].

8. Изменение Политики

Оператор вправе вносить изменения в настоящую Политику. Актуальная редакция размещается на данной странице. Дата последней редакции: [ДАТА РЕДАКЦИИ].
