# Спецификация по рефакторингу проекта Amigo

Эта спецификация описывает план рефакторинга текущего одностраничного лендинга (`index.html`). Цель рефакторинга — улучшить читаемость кода, разделить логику, стили и разметку (Separation of Concerns), а также подготовить проект к легкому масштабированию и поддержке.

## 1. Реорганизация файловой структуры

Создание понятной иерархии папок для хранения статики.

### `css/style.css`
Перенос всех стилей из тега `<style>` в отдельный файл. Стили будут сгруппированы по логическим блокам:
- Variables (CSS-переменные)
- Глобальные сбросы (Reset/Normalize)
- Typography (Типографика)
- Components (Кнопки, бейджи)
- Sections (Header, Hero, Advantages, Integrations, Pricing, Footer)
- Media Queries (Адаптив)

**Оптимизация единиц измерения:**
- Провести аудит CSS-кода на наличие жестко заданных размеров в пикселях (`px`) для отступов (`margin`, `padding`), размеров шрифтов (`font-size`) и габаритов блоков.
- Заменить абсолютные величины в пикселях на относительные единицы измерения (`rem`, `em`, `%`, `vh`, `vw`) для улучшения адаптивности, масштабируемости и Accessibility.

### `js/main.js`
Перенос логики параллакс-эффекта кубиков из тега `<script>` в самом низу HTML-документа. Добавление обработчика `DOMContentLoaded` для безопасного запуска скрипта.

### `assets/images/cube-wireframe.svg`
Перенос огромного Data URI (кода SVG-изображения куба из класса `.cube`) в отдельный физический SVG-файл. Это сильно очистит CSS-файл и сделает его более читаемым.

### Обновление `index.html`
- Удаление тега `<style>` и подключение внешнего файла `<link rel="stylesheet" href="./css/style.css">`.
- Удаление инлайн `<script>` и подключение внешнего скрипта `<script src="./js/main.js" defer></script>`.
- Добавление базовых SEO мета-тегов (`description`, Open Graph).
- Проверка атрибутов для улучшения доступности (a11y).

## 2. Ожидаемая структура директории после рефакторинга:

```text
/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    └── images/
        └── cube-wireframe.svg
```

## 3. Этапы проверки (Verification Plan)
1. Открыть `index.html` в браузере.
2. Убедиться, что все стили применились корректно (отсутствуют визуальные поломки).
3. Проверить работу скрипта анимации кубиков при движении мыши в Hero-блоке.
4. Проверить консоль браузера на отсутствие ошибок загрузки ресурсов (404 Not Found для CSS, JS или картинок).
